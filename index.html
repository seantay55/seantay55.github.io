Chrome Extension · Claude AI

Fandom Redirector

Fandom wiki pages are notoriously slow — so I used Claude AI to build a fix. I described the problem, and Claude wrote a Chrome extension from scratch using Manifest V3 and the webNavigation API that automatically intercepts any fandom.com URL and redirects it to the faster Antifandom mirror before the page even loads. A real problem, solved in a conversation.
